# SQL 查询窗体规格

适用：SQL 查询窗体的布局、查询页签、查询菜单、查询方案列表、连接树选中状态和左右分栏。

触发：修改 `UI/QueryEditorForm.cs`、`UI/SqlEditorControl.cs`、`Services/QuerySchemeNote.cs` 之前，先完整读本文。

通用窗体、按钮、悬浮说明、边框和尺寸记忆规则见 `ui-common.md`。

## 规则

- SQL 区标题为「SQL编辑器（仅限只读查询）」。左栏标题为「数据库连接」。
- SQL 编辑器使用 AvalonEdit。语法高亮与 SQL 页正文共用 AvalonEdit 自带的 T-SQL 定义，颜色和粗体以该定义为准。
- SQL 编辑区用页签，一页一份查询，不限制个数。标题是方案名称；编辑器内容和上次保存的 SQL 不一致时，标题末尾加 *。新建页签的标题是「新建查询」加最小未占用的正整数，已打开页签和已保存方案都算占用。页签是普通 `TabControl`，标题左侧是脚本图标，关闭标记在标题文字右侧，例如「新建查询1」后面的「×」，比标题字大一号。有修改时先问是否保存，空的新建查询直接关。关掉最后一个页签后页签控件藏起，新建图标留在页签条左端。有页签时，新建图标紧挨最后一页的右侧；页签多到放不下时，图标停在页签条右端，页签停在图标左边。页签放得下时不显示左右箭头。放不下时箭头留在加号左边。重新打开查询窗后，页签标题整行可见，不被加号挤没。编辑器在页签条下面，不放进页签页里。没有查询时，编辑区居中放一颗平按钮「请新建查询」，底色与空白区相同，没有边框和凹凸，点击与菜单「新建查询」相同。周围空白处右键仍可新建。数据库连接、查询方案、SQL 编辑器和结果预览四块各有一条较浅的 1 像素边框，颜色用系统的 ControlDark。这条边只描边，区域内部不跟着变深。结果预览折起来时那条边不显示。对话栏展开时同样有这条边。标题行不再放按钮。预览、写入 Sheet 和保存方案在「最大预览行数」说明的右侧，与说明同一行，图标 28 像素。文字都放在悬浮说明里。新建页签的图标是加号。关闭整个窗体时，对每个有修改的页签同样询问，取消则不关窗。
- 页签右键为新建、保存、重命名。点在页签空白处时只有新建可用。页签旁的新建图标不代替这个菜单。查询菜单在「保存方案」后有「重命名」。「查询 → 关闭」仍关闭整个窗体。未保存的重命名只改标题。已保存的重命名立刻改方案名称，不把编辑器里尚未保存的 SQL 写回。重名时沿用覆盖确认。
- 左侧方案列表点一项：已经打开则切换到该页签，否则新开一页，不覆盖其他页签里的 SQL。删除方案时关掉对应页签，不另开空白页。鼠标停在某一项上约半秒显示该项，字段与顺序同悬停。连接已删除时连接写「连接已删除」，没有记录的人写「未知」。移开或换到另一项就关掉。
- 保存方案时，在 SQL 开头写入或整块替换一块说明注释，六行标签和顺序与悬停相同。创建人只在第一次落盘时写入；已经存在且没有创建人的方案保持为空，说明里写「未知」，不用当前用户回填。修改人每次保存写成当前 Windows 用户名和 Excel 或 WPS 选项里的用户名，两个名字相同或读不到表格用户名时只留 Windows 用户名。创建时间沿用方案已有的创建时间。重命名只改方案名称，不改 SQL，说明里的名字要等下次保存才更新。判断 SQL 是否为空时先拿掉这块说明，只剩说明时仍提示输入 SQL。说明留在送去执行的 SQL 里，数据库把它当注释。
- 只有一个菜单，四项为连接、查询、编辑、AI。AI 是无图标的文字项，点击展开或收起右侧对话栏。只收起再展开不新建对话；新开和关闭查询窗如何开始、结束对话见 `ai-assistant.md`。
- 当前连接根节点显示 `名称 [当前]`。名称加粗，`[当前]` 用非粗体灰色与名称区分；未选中时名称行使用浅色高亮底 RGB(255,243,205)，图标保持彩色。用 `session.activeConnectionId` 记住，打开时直接显示，不要为了显示当前连接而重新测试。
- 没有结果时预览区保持折叠。展开后编辑区与预览区高度为 1:1。预览表格只有一份，每个页签记住自己上次的预览；切换时恢复该页结果，没有预览过的页签保持折叠，不在后台刷新。
- 左右默认 1:5。左栏最小宽度 140，右栏 420。比例键为 `session.workspaceSplitRatio`。
