# 批量刷新规格

适用：批量刷新窗的任务列表、SQL 页参数解析、美化格式、状态圆点、刷新进度和结束说明。

触发：修改 `UI/SheetRefreshForm.cs`、`Services/BatchRefreshService.cs`、`Excel/SqlSheetTaskReader.cs`、`Excel/SqlSheetTaskParser.cs` 之前，先完整读本文。

通用窗体、按钮、悬浮说明、边框和尺寸记忆规则见 `ui-common.md`。

## 规则

- 当前工作簿没有名为 SQL 的工作表（忽略大小写）时提示错误，不打开窗体。通过工作表检查后，再按 `ui-common.md` 的连接方案规则。
- 左栏是与 SQL 查询窗体共用的数据库连接树，当前连接仍用 `session.activeConnectionId`。右栏是任务列表。左右默认 1:4，左栏最小 160，右栏 480，键为 `session.refreshSplitRatio`。不与查询窗体的分栏比例混用。
- SQL 页每一列是一个任务。第 1 行是目标表名，可在 `//` 后写 `键=值`，分号分隔。当前执行「起始单元格」（默认 A1，结果表左上角，含标题行）和「清空多余列」（默认是，不写也会清空原数据区域里结果没有覆盖的列）。其他键原样保留并显示，暂不执行。已知键写坏时该行标红并跳过，不让整批失败。刷新前的提示写出目标表和具体错误；已勾选任务全部写坏时不开始刷新。
- 目标表名忽略大小写后必须唯一，否则报错且不刷新。
- 第 2 行起、SQL 命令之前的 `--` 与 `/* */` 注释作为列表摘要，仍留在送去执行的 SQL 里。查询方案保存时写在开头的那块说明不计入摘要；它后面的用户注释继续作为摘要。
- 批量刷新窗有一个「格式」菜单。「美化格式」先清空 SQL 页全部单元格格式，再只改第 1 行有表名的列的字体和颜色，不改单元格文字，也不改列宽，不画单元格边框。然后冻结首行，并把工作表标签设为标签颜色。冻结失败时颜色仍然保留。没有可美化的列时不打开进度窗，手动点「美化格式」时弹出「没有可美化的列。」并点确定。有列时走进度窗，按列推进，可取消；当前列做完再停，已完成的列保留。成功或取消后进度窗关闭，失败时进度窗留下，关闭后再看错误详情。手动美化成功后弹出「已美化 N 列。」并点确定；取消不弹这层框。刷新结束后的自动美化不另加框，结果仍由刷新结束说明承担。字体为 Cascadia Code Light 10。第 1 行表名加粗，`//` 及其后为灰色。第 2 行起的正文按 AvalonEdit 自带的 T-SQL 定义上色，粗细和颜色以该定义为准。公式格用公式色和由其淡出的底色。表名、公式、标签这三项颜色，以及「保存后美化」「刷新后美化」，在参数设置的「sql页格式」页，每项有说明。改完要点保存，不立刻重画。「格式设置」打开这一页。查询勾选把 SQL 写入 Excel 且写入成功后，若「保存后美化」为开（默认开），再走一遍美化。批量刷新正常结束后，若「刷新后美化」为开（默认关），在结束说明之前再走一遍美化；有失败或截断的任务也美化，取消或抛错不美化。这次美化被取消或失败时仍弹出刷新结束说明。关掉自动美化时，新写入的列保持未美化，直到手动点「美化格式」。改写第 1 行时只重套该格的表名色，不改标签色。手改单元格后要再点「美化格式」。
- 已知参数「起始单元格」「清空多余列」分列显示并带表头说明，其他键按出现顺序各占一列。两个已知值都是默认且没有其他键时，首行只留表名。点击 SQL 摘要跳到命令首行，没有摘要时显示「无」；点击目标表名跳到该表，表不存在时不新建。状态用圆点：灰是待刷新，浅绿是成功，橙是成功但结果被截断，红是失败或参数、重名错误。未勾选时状态列不着色。成功和截断颜色在参数设置的「Excel」页，待刷新和失败颜色在「批量」页。改完要点保存，下次重画圆点才用新颜色。首次打开默认不勾选。勾选列表头是全选复选框，没有单独的全选按钮。单击勾选框只切换该行，并作为下一次连续勾选的起点。按住 Shift 点击另一行时，从起点到该行全部改成起点那次的勾选结果，起点不变；按住 Shift 时不跳转。没有起点时 Shift 点击只切换被点的那一行。重新读取任务后起点作废。列表不使用多行高亮选择。任务行右键「复制结果信息」复制该行结果说明；说明为空时该项不可用。
- 进度不能误导用户。算不出完成比例时不要显示精确百分比。进度条只向前，不能因为后到的快照往回走。读取进度只有已结束个数和总数，文字和条都从这一对数字画出，不另报百分比。读取个数达到总数后，后到的读取快照不能改读取条和阶段标题。写入阶段不再改读取条。写入条的序号和填充来自同一次快照，改完后立即重画，不等 Excel 重画恢复。
- 写入每张目标表前激活该表，并把起始单元格滚到视口左上角。写入期间关闭 Excel 重画，写完恢复进入前的重画开关，结果只显示一次。不把 Excel 抢到进度窗前面。激活或滚动失败时继续写入，不让该任务失败。进度窗仍置顶居中。
- 正常结束后的说明：计数在上，失败和截断明细在中（没有则不显示）。明细不写单独的段标题。每条失败是「× [失败] 「表名」：说明」，每条截断是「△ [截断] 「表名」：说明」，说明跟在同一行。没有说明时只留标记和表名。截断说明写出已读取行数和上限行数。失败在前，截断接在后面，中间不空行。标题行底色是底部独立图例。图例色块与标题行相同：浅绿色是本次写入成功且结果完整，橙色是写入成功但结果达到最大导出行数后被截断。这两种颜色与状态圆点相同，在参数设置的「Excel」页。正文（计数和明细）用白底，图例与窗体同色、两行紧凑，文字用较小的灰色斜体。取消或异常不弹出该说明。
