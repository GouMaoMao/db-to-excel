# 预览与写入规格

适用：查询结果预览、行数上限、预览右键菜单、导出为 Excel、写入 Sheet 和交互查询的写入流程。

触发：修改 `Excel/ExcelResultWriter.cs`、`Services/QueryBufferService.cs`，或 `UI/QueryEditorForm.cs` 的预览与写入路径之前，先完整读本文。

通用窗体、预览表头自绘和悬浮说明规则见 `ui-common.md`。写入后的美化格式规则见 `batch-refresh.md`。

## 规则

- 不要把 LIMIT 或 TOP 拼进用户 SQL。
- 仅预览时加会话行数上限，值为「最大预览行数 + 1」：MySQL 用 `SQL_SELECT_LIMIT`，SQL Server 用 `ROWCOUNT`。PostgreSQL、SQLite 和 DuckDB 没有对应会话设置，不要改写 SQL。
- 导出使用最大导出行数，不套预览用的会话行数上限。
- 达到上限后仍 `Cancel()` 以停掉服务器；释放读取器时吞掉因此产生的异常，不能把截断当成操作失败。
- 状态要写出已读行数和上限，并提示可在设置中修改「最大预览行数」。
- 预览表头两行：字段编码加粗，下一行是 CLR 类型短名、斜体、灰色。
- 结果预览右键按点击位置切换。点数据格、行号或空白处为复制、复制带标题、全选、导出为 Excel。点列标题只有复制标题。点未选中的格子时先改成只选中该格；点已在选区里的格子则保留选区。点列标题时选中该列。点行号时，若该行不在选区里，改为选中整行。预览表有焦点时 Ctrl+C 复制，Ctrl+Shift+C 复制带标题，Ctrl+A 全选；这些按键不作用于 SQL 编辑器。复制有选区时只含选中格子，没有选区时复制全部数据行，不含行号。复制带标题在数据前加两行，第一行字段编码，第二行 CLR 类型短名。复制标题是被点中那一列的字段编码和类型短名，没有类型时只留字段编码。导出为 Excel 先选择 xlsx 路径，把当前已查出的预览写入新文件，不重新查询，不改当前工作簿。路径不能是当前已打开的工作簿。取消或失败时不留下临时工作簿。零行但有列时仍可导出，文件里只有标题。没有数据行时复制、复制带标题和全选不可用。导出正常结束后弹出与状态栏相同的一句，必须点确定；结果被截断时用警告图标。取消或失败不弹这层框。
- Excel 写入只清除目标区域内的值。原先单元格上的数值格式、字体、对齐和填充保留；本次多出来的行、列不继承这些格式。标题只占一行字段编码，编码行加粗，这一步只改加粗和底色。成功时底色默认为浅绿 RGB(101,219,91)，结果被截断时默认为橙色 RGB(255,184,98)，与批量刷新状态圆点相同。待刷新圆点默认 RGB(162,162,162)，失败圆点默认 RGB(217,57,57)。已写入的标题行不因改设置而重画，下一次写入才用新底色。数据从第 2 行开始。清空范围内的边框会去掉；写完后只在标题和数据组成的区域重新画灰色细网格线 RGB(128,128,128)。
- 交互查询写入前弹出目标表名。输入框默认当前查询方案名，用户可改。方案不记住上次的表名。表已存在时须确认覆盖，取消则不写结果也不写 SQL。同一窗体可选择把 SQL 写入工作表 SQL：第 1 行是这次确认的目标表名，第 2 行留空，第 3 行起一行一个单元格且不换列。没有同名列时追加到已用区域右侧，已有同名列则更新该列并清掉旧行。以 `--` 开头的行写入前加一个空格，避免 Excel 把减号当成公式。写入成功且「保存后美化」为开时，按 `batch-refresh.md` 的「美化格式」规则美化整张 SQL 页。未勾选保存 SQL、取消或写入失败时不美化。整段正常结束后只弹一次与状态栏相同的一句，必须点确定。被截断时说明已达「最大导出行数」，并用警告图标。美化被取消时仍弹出该句。美化失败只留错误详情，不再叠一层写入成功框。取消或写入失败不弹这层框。
