# 窗体与界面通用规格

适用：所有继承 `AppForm` 的窗体，以及按钮、页签、菜单、滚动条、复选框、悬浮说明、分隔线、自绘、居中、尺寸记忆和连接树显示。

触发：改动 `UI/` 下任何文件、新增 `AppForm` 派生窗体、`UI/AppPresentation.cs`、`UI/WrapLabel.cs`、`UI/AddItemList.cs`、`UI/CloseMark.cs`、`UI/DatabaseConnectionTree.cs` 之前，先完整读本文。

## 规则

- 所有应用窗体显示嵌入的 rocket.ico，不用 WinForms 默认图标。
- 界面字体用 Microsoft YaHei UI。进度日志用 Consolas。SQL 编辑器和 SQL 页都用 Cascadia Code Light 10。编辑器缺失时依次回退 Cascadia Code、Consolas、微软雅黑 UI。
- 功能窗体继承 `AppForm`。窗口骨架统一用 `AppForm` 的 `InitializeWindow`；有根表格和底部按钮栏的窗体用 `CreateRootTable`、`CreateActionBar`，不要在每个窗体里再复制一套。按钮、页签、菜单、滚动条和复选框走系统当前主题，按钮使用 `UseVisualStyleBackColor`。外观以参数设置窗体为准：控件是平的，当前页签和内容区相接。
- 可以点选的控件都要有悬浮说明，文案写在 `UI/AppPresentation.cs`。第一行是概述，换行后是详述。例如发送按钮是「发送」，换行后再写这次会带上什么、不会带上什么。
- 需要分隔时用一条平线。文本框和列表用 `BorderStyle.FixedSingle`，或 1 像素实线。查询编辑器和进度日志同样用这种单线边。
- 需要随窗口宽度折行的说明统一用 `WrapLabel`，不要再为说明标签各写一套 `Resize`/`MaximumSize` 宽度钩子；表格宽度和滚动条适配仍可保留自己的布局逻辑。
- 自绘只画系统主题表达不了的内容：名称旁的图标、预览表头的两行字、状态颜色、勾选框里的自定义勾选。连接树、查询方案列表、预览表头，以及模型设置和 Skill 设置的带「新增」末项列表继续自绘。要关掉的文字在末尾留出空位。「×」由 `CloseMark` 画得比正文大一号，点击是否落在标记上只用 `CloseMark`，不要再做单独的关闭按钮。页签标题和输入区引用都走这里。
- 进度窗口在任务成功后自动关闭；只有出错时保留，供用户查看。
- 查询方案信息在鼠标停在该方案上约半秒后显示，字段为方案、连接、创建人、创建时间、修改人、修改时间。
- 记住尺寸的功能窗体相对工作区居中，使用 `FormStartPosition.Manual`；不记尺寸的小窗按父窗、工作区或目标区域居中。
- 左右分割比例只有用户拖动分割条时才把千分比写入设置。缩放、最大化、还原只按已存比例重算。值为 0 表示尚未记住，用该窗默认比例。
- 记住宽高和最大化状态的功能窗体，键为 `session.formBounds`：SQL 查询、批量刷新、连接管理、设置、JDBC 环境、模型设置、Skill 设置、AI 对话。进度、文本输入和只读说明（含写入 Sheet）、连接编辑、请求详情、错误详情、刷新说明、本地数据、打开提示这些小窗不记。
- SQL 查询和批量刷新已经打开时，再次点击功能区只激活。一个连接方案都没有时不打开窗体，提示先点击功能区「连接管理」再点「新建」。
- 第一次打开 SQL 查询或批量刷新时，窗体在分栏按最终尺寸摆好之前不显示；批量刷新的任务列表也在这时填完。打开可以稍慢。批量刷新若读到重名或读取失败，在主窗体出现之后再提示。不等待对话栏里的浏览器。
- 打开提示是无边框小窗，440×148。文案「正在打开…」为 18 磅，左侧是 32 像素的 icon_robot.png。图标和文字作为一组居中。SQL 查询和批量刷新共用这一提示。
- 连接树里表和视图的注释用灰色斜体，编码保持正文字体。注释只显示数据库目录里的内容；没有或目录失败时只显示编码，不中断展开，不弹错误窗。整批为空记 Information，目录抛错记 Warning。Oracle 等 REMARKS 为空时，由用户在 JDBC URL 里打开 `remarksReporting=true` 或对应 remarks 参数。
