## 已实现的自动化测试

### SQL 只读校验（8 个）

- 接受普通 `SELECT`、CTE 和末尾分号。
- 拒绝空查询、非查询语句和多语句。
- 忽略注释、字符串字面量和引用标识符中的禁用关键字。
- 拒绝 `SELECT INTO`、行锁定子句和 PostgreSQL `RETURNING`。
- 报告未闭合的块注释和字符串或标识符。

### 设置注册与定义（7 个）

- 默认核心设置注册、排序及大小写无关键查找。
- 空定义和重复键拒绝。
- 整数范围、批量模式和日志级别解析。
- 设置值序列化及类型检查。

### SQL Sheet 解析（4 个）

- 每列一个任务并保留实际源列编号。
- 第 1 行目标 Sheet 名修剪。
- 第 2 行起忽略空单元格并按换行拼接 SQL。
- 空目标或空 SQL 跳过，并支持非零二维数组下界。

### JSON 设置存储（8 个）

- 文件不存在时读取默认值，单项和批量设置可持久化。
- 非法值与未知批量键在写入前整体拒绝。
- 批量保存只触发一次变更事件。
- 未知键在后续保存中保留，返回的原始值与内部状态隔离。
- 非法持久值回退默认值，损坏 JSON 自动备份。

### 连接方案仓储（7 个）

- ID 分配、保存、覆盖、删除和大小写无关查找。
- 名称排序、输入复制隔离及只读快照。
- 变更事件、必填字段校验和损坏 JSON 备份。

### 查询方案仓储（7 个）

- ID 分配、更新时间、保存、覆盖、删除和大小写无关查找。
- 名称排序、输入及返回值复制隔离。
- 必填字段校验、空扩展选项归一化和损坏 JSON 备份。

## 后续自动化测试范围

### 批量调度

`BatchRefreshService` 的公共入口和结果写入器直接依赖 Excel COM `Workbook`，并要求 Excel UI `SynchronizationContext`。在该边界解耦前，不创建脆弱的 Office COM mock；以下场景保留为真实 Excel 集成测试或未来解耦后的单元测试范围：

- 串行顺序。
- 最大并发数限制。
- 重复目标 Sheet 跳过。
- 单任务失败不终止其他任务。
- 取消传播。
- 结果统计和进度聚合。
